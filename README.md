# לוחמי דרקונים 🐉⚔️

משחק תרגול חשבון בעברית לכיתה ה', לקראת מבחן תחילת שנה.
אתר סטטי בלבד: HTML, CSS ו-JavaScript רגיל. אין שרת, אין שלב בנייה.

## איך מפעילים במחשב

לחיצה כפולה על **start-game.cmd**. נפתח חלון שחור (זה השרת הקטן) והדפדפן נפתח על המשחק.
לסגירה: סוגרים את החלון השחור.

> חשוב: אי אפשר לפתוח את `index.html` בלחיצה כפולה, כי המשחק בנוי ממודולים של JavaScript
> שדורשים שרת. `start-game.cmd` עושה את זה בשבילכם.

## מבנה הקבצים

```
index.html            המסכים
css/styles.css        עיצוב, כולל כללי RTL/LTR
js/main.js            הפעלה, ניווט, גיבוי ושחזור
js/storage.js         שמירה ב-localStorage, גרסאות ומיגרציה
js/questions.js       מנוע השאלות - גנרטורים + שאלות המורה
js/progress.js        מטבעות, ניסיון, דרגות, רצף וסטטיסטיקה
js/battle.js          לולאת הקרב
js/avatar.js          ציור הלוחם והדרקון (SVG שכבתי)
js/monsters.js        המפלצות
js/shop.js            קטלוג הציוד
js/ui.js              מסכים, חלוניות, מקלדת מספרים
tests/                בדיקות אוטומטיות
```

## בדיקות אוטומטיות

אם מותקן Node.js:

```
node tests/test-generators.mjs
node tests/test-modules.mjs
```

הבדיקות מוודאות שכל גנרטור מחזיר תשובה נכונה (בחישוב עצמאי), שהמספרים מוצגים עם
מפרידי אלפים, שתרגילים לא מתהפכים בתוך טקסט עברי, ושמנגנון השמירה והמיגרציה עובד.

## שמירת התקדמות

ההתקדמות נשמרת בדפדפן (localStorage) אחרי כל שאלה.
במסך "הגדרות וגיבוי" אפשר להוריד קובץ גיבוי, לשחזר ממנו, או להעתיק/להדביק את הגיבוי כטקסט.
